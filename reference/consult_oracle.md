# Consult the Pythia

Need some help? Ask the oracle.

## Usage

``` r
consult_oracle(query)
```

## Arguments

- query:

  something you would like to know

## Value

a random response from the oracle

## Examples

``` r
consult_oracle(12345L)
#> 
#> ── The oracle says:  ──
#> 
#> ❓ You may rely on it.
#> 
consult_oracle("A")
#> 
#> ── The oracle says:  ──
#> 
#> ❓ Outlook not so good.
#> 
```
